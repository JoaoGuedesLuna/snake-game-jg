<div align="justify">
  <h2>📖 About the Project</h2>

  <p>
    <strong>SnakeGame.JG</strong> is a classic Snake game developed using <a href="https://scratch.mit.edu/">Scratch</a>, a visual programming platform designed to make programming accessible and interactive.
  </p>

  <p>
    The objective is to control a snake, collect food, increase your score, and survive for as long as possible without colliding with the walls or the snake's own body.
  </p>

  <p>
    This project explores fundamental game development concepts through an interactive and engaging experience.
  </p>
</div>

<div align="justify">
  <h2>🕹️ How to Play</h2>

  <ol>
    <li>Open the game using the Scratch link above.</li>
    <li>Start playing and control the snake using the game's controls.</li>
    <li>Collect food to increase your score and grow longer.</li>
    <li>Avoid colliding with the walls or your own body.</li>
    <li>Keep playing to achieve the highest score possible.</li>
  </ol>

  <p>
    <strong>Objective:</strong> Survive as long as possible while collecting food and achieving the highest score.
  </p>
</div>
